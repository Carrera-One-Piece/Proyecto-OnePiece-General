# Proyecto-OnePiece-General

Bienvenido al repositorio central de desarrollo - Carrera de la gran ruta hacia el One Piece. Este proyecto está construido con **PHP**, **Laravel** e integra mapas interactivos con **Leaflet.js**.

---

## Stack Tecnológico

* **Back-End:** PHP 8.2+ / Laravel 11.x
* **Mapas & Geolocalización:** [Leaflet.js](https://leafletjs.com/)
* **Base de Datos:** MySQL / PostgreSQL
* **Control de Versiones:** Git & GitHub

---
